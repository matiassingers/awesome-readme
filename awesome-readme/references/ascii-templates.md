# ASCII Art Templates

Use Unicode box-drawing characters for architecture diagrams. Renders everywhere, no broken image links.

## Characters

```
┌ ┐ └ ┘ │ ─ ┬ ┤ ┴ ├ ┼
▶ ◀ ▲ ▼ → ← ↑ ↓
```

## Simple Pipeline

```
┌──────────┐     ┌──────────────┐     ┌──────────┐
│  Input   │────▶│   Process    │────▶│  Output  │
└──────────┘     └──────────────┘     └──────────┘
```

## Client-Server

```
┌──────────────┐          ┌──────────────────────┐
│    Client    │◄────────▶│      Server          │
│   (Browser)  │   HTTP   │   ┌──────────────┐   │
└──────────────┘          │   │   Database   │   │
                          │   └──────────────┘   │
                          └──────────────────────┘
```
